# Deployment

Upload the contents of this project into `/tools/egg-rate-today/`.

Public URL: https://bagchi.in/tools/egg-rate-today/

If the domain already has a root `/robots.txt`, add:
`Sitemap: https://bagchi.in/tools/egg-rate-today/sitemap.xml`

Run the GitHub Actions workflow manually once to fetch live data, then it will update daily.
